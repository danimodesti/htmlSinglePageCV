# htmlSinglePageCV

This is a HTML practice project proposed by the roadmap.sh community. Its purpose is to create a simple CV page structure.

## Instructions to run
As this is a simple HTML file, in order to run it you can just download it and/or open it with your preferred browser or with the live server VS Code extension (or similar).
